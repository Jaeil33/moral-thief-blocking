# 「도덕적 도둑」 Blocking 뷰어

**바로 보기: https://jaeil33.github.io/moral-thief-blocking/**

연극동아리 지대로 제32회 정기공연 「도덕적 도둑」(작 다리오 포, 각색·연출 김재일, 2026년 1학기)의 배우 동선(Blocking)을 장면별로 보는 페이지입니다.

- 위쪽 눈금자에서 장면을 고르거나 ← → 키로 넘깁니다. 인물을 고르면 그 인물의 동선만 강조됩니다.
- 무대 평면도의 번호, 오른쪽 동선 목록의 번호, 대본 여백의 번호는 같은 이동을 가리킵니다.
- 장면 12개, 이동 146건. 대본에서 뽑은 '반드시 지킬 사실' 118건과 대조했고, 자동 검증 오류는 0건입니다.

동선은 Claude Code로 만든 Blocking 하네스가 생성했습니다. 하네스는 초안 → 자동 검증(오류 규칙 15개, 경고 규칙 9개) → 체크리스트 검토 → 개선 순서로 돌아갑니다. 이 저장소에는 그 결과로 나온 뷰어(HTML 한 장)만 올렸습니다.
